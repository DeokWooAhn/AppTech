# AppTech 앱

## 캐시스크린 클론 코딩


### 프로젝트 소개
ios 및 swift 공부용 클론 코딩 프로젝트

### ⚙️ 개발 스팩

UI: SwiftUI

아키텍처: Clean Architecture
        MVVM 패턴
        DI 적용

데이터 저장: UserDefaults
